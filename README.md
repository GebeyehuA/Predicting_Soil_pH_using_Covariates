# Predicting_Soil_pH_using_Covariates
Machine learning workflow for spatial soil pH estimation (60–100 cm depth) using environmental, topographic, and spectral covariate datasets processed via Google Earth Engine and Google Colab.


## 📁 Dataset Source & Methodology
* **Original Implementation:** Tested and developed using the **R programming language**.
* **Source Material & Tutorials:** Adapted from the Digital Soil Mapping (DSM) book resources for [Random Forest-based Regression Implementation](https://smartdigiag.com/DSM_book/pages/dsm_cont/sspfs/rf/).
* **Data Covariates:** Includes environmental, topographic, and spectral covariates (such as elevation, slope, TWI, NDVI, and Landsat bands) used to predict soil pH (`pH60_100`).
